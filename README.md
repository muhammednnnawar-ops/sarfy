# 🏦 Sarfy (صرفي) - منصة الإدارة المالية والمحافظ الذكية

تطبيق ويب مالي متكامل (Financial & Wealth Management Platform) لإدارة الحسابات البنكية، المحافظ الإلكترونية، التدفقات النقدية، الاشتراكات الدورية، الديون، والأهداف المالية. يتميز بالعمل الفوري على السيرفر مع مزامنة سحابية ذرية بقاعدة بيانات **MySQL**، ودعم العمل دون إنترنت (**PWA Offline Mode**)، وتجربة مستخدم فاخرة بالوضع الليلي مع لوحة تحكم حصرية لمالك التطبيق.

---

## 🚀 المميزات الرئيسية (Core Features)

1. **إدارة الحسابات والمحافظ (Multi-Account Management):**
   - كاش، بنوك، محافظ ذكية (فودافون كاش، إنستاباي)، بطاقات ائتمانية.
   - بطاقات تفاعلية بنكية أنيقة مع أرصدة حية وتتبع الإجمالي.

2. **تسجيل العمليات والتدفقات النقدية (Cashflow Tracking):**
   - تسجيل عمليات الدخل (مستلم / متوقع) والمصروفات بتصنيفات دقيقة وميزانيات ذكية.
   - تحويلات بين الحسابات وتتبع الرسوم.

3. **لوحة تحكم حصرية لمالك التطبيق (Owner & Admin Dashboard):**
   - 4 بطاقات إحصائيات عليا لمراقبة أداء المنصة (إجمالي العملاء، الحسابات النشطة، العمليات، والأموال).
   - جدول تفاعلي للتحكم في حسابات العملاء: تفعيل / تعليق الحسابات (Active / Suspended)، ترقية الرتب، حذف الحسابات شلالياً، وإضافة عملاء جدد.

4. **نظام صلاحيات متقدم (Role-Based Access Control):**
   - عزل تام بين مالك التطبيق والعملاء في قاعدة البيانات؛ كل عميل لا يرى ولا يصل إلا لبياناته وسجلاته المالية الخاصة.

5. **المزامنة السحابية ودعم الأجهزة المتعددة (Multi-Device Sync):**
   - دعم كامل لتسجيل الدخول الفوري المتزامن من الهواتف وأجهزة الكمبيوتر المختلفة عبر قاعدة بيانات MySQL.
   - التحقق المركزي من بيانات الدخول (البريد، كلمة المرور، الرمز السري PIN).

6. **أمان عالي وواجهة خصوصية:**
   - أيقونات عصرية ناعمة للتحكم في إظهار وإخفاء كلمات المرور وإخفاء المبالغ الحساسة في الأماكن العامة.
   - حماية من محاولات التخمين (Rate Limiting).

## 🛠️ البنية التقنية (Tech Stack)

* **الواجهة الأمامية (Frontend):** React 18, Pure JSX, Vanilla CSS3 (Bento Grid / Neumorphic / Glassmorphism), Handcrafted SVG Icons.
* **البناء والحزم (Bundler):** esbuild - تجميع التطبيق بالكامل داخل ملف واحد مستقل `index.php` فائق السرعة.
* **الخلفية (Backend):** PHP REST API (`api.php`) مبني بـ PDO مع معاملات Transactions للأمان والسرعة.
* **قاعدة البيانات (Database):** MySQL 8 / MariaDB بترميز `utf8mb4_unicode_ci`.
* **العمل دون اتصال (Offline):** Progressive Web App (PWA) عبر `manifest.json` و `sw.js`.

## 🔑 الحساب الأول (المالك)

لا توجد حسابات افتراضية بكلمات مرور معروفة. أول مستخدم يسجّل من شاشة **مستخدم جديد** يصبح مالك المنصة (Owner)، وبعدها يمكنه إضافة العملاء من لوحة الإدارة.
للتجربة بدون سيرفر استخدم زر **استكشاف الحساب التجريبي** في شاشة الدخول.

## 💻 التشغيل المحلي (Local Development)

```bash
# تثبيت الاعتماديات
npm install

# بناء ملف index.php المستقل (يتضمن الواجهة كاملة)
npm run build

# تشغيل خادم معاينة للواجهة فقط (وضع عدم الاتصال) على http://localhost:3000
npm start

# أو تشغيل الواجهة مع api.php عبر PHP (يتطلب MySQL و config.local.php)
php -S localhost:8080

# تشغيل الاختبارات
npm test
```

## 🌐 النشر على الاستضافة (cPanel / HostArmada)

1. أنشئ قاعدة بيانات ومستخدم في cPanel مع منحه **ALL PRIVILEGES**.
2. استورد ملف `sarfy-database.sql` عبر **phpMyAdmin**.
3. عدّل بيانات الاتصال في `config.php`.
4. ارفع ملفات المشروع إلى مجلد الموقع (`public_html`).
