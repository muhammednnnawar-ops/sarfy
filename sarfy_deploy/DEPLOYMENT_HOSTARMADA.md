# دليل رفع وتشغيل تطبيق «صرفي» (Sarfy) على استضافة HostArmada (Speed Reaper) مع قاعدة بيانات MySQL

تهانينا! تطبيق **«صرفي» (Sarfy)** يدعم الآن **التخزين المركزي والمزامنة السحابية الذرية عبر قاعدة بيانات MySQL** مع الحفاظ على التشفير والعمل بلا إنترنت (Offline Mode) دون أي تعطل.

---

## 📁 حزمة الملفات المرفقة

| الملف | الوصف والغرض |
|---|---|
| **`index.html`** | واجهة التطبيق الكاملة المستقلة (Single Standalone Web App) مدمج بها React 18، التصميم المستقبلي، وكافة الرسوم البيانية. |
| **`config.php`** | ملف إعدادات الاتصال بقاعدة بيانات MySQL (المضيف، اسم القاعدة، اسم المستخدم، كلمة المرور). |
| **`api.php`** | الواجهة البرمجية الخلفية (PHP REST API) المبنية بتقنية PDO ومعاملات Transactions لحفظ ومزامنة كافة الجداول علائقياً. |
| **`sarfy-database.sql`** | مخطط وهيكل قاعدة بيانات MySQL وجداولها الـ 12 مع البيانات النموذجية والترميز `utf8mb4_unicode_ci`. |
| **`sarfy-database.json`** | نسخة احتياطية بصيغة JSON لكافة البيانات. |
| **`htaccess.txt`** | ملف إعدادات خادم LiteSpeed (أعد تسميته إلى `.htaccess` داخل cPanel). |
| **`manifest.json` + `sw.js`** | ملفات تثبيت التطبيق على الهواتف (PWA) والعمل دون اتصال إنترنت. |

---

## 👑 حسابات النظام وصلاحيات لوحة المالك (RBAC)

تطبيق **«صرفي»** يدعم الآن **نظام صلاحيات متقدم يفصل بين مالك التطبيق وعملاء المنصة**:

### 1. حساب مالك التطبيق (Owner / Admin)
- **البريد الإلكتروني:** `admin@sarfy.app`
- **كلمة المرور الافتراضية:** `demo1234`
- **الرمز السري (PIN):** `1234`
- **المزايا:**
  - ظهور تبويب حصري في القائمة الجانبية: **👑 إدارة التطبيق والعملاء**.
  - لوحة تحكم كاملة تعرض: إجمالي العملاء، الحسابات النشطة، إجمالي العمليات، وإجمالي أرصدة المنصة.
  - جدول تفاعلي بالعملاء مع إمكانية:
    - البحث والفلترة.
    - تفعيل أو تعليق الحساب (Active / Suspended).
    - ترقية العميل لمشرف أو تخفيض الرتبة.
    - حذف الحساب وحذف كافة سجلاته المالية بشكل شلالي (Cascade).
    - إضافة عميل جديد مباشرة من اللوحة.

### 2. حسابات العملاء (Client Users)
- كل عميل يسجل في التطبيق يتم عزله بالكامل في قاعدة البيانات ولا يمكنه رؤية سوى سجلاته وبياناته الخاصة.
- لا يظهر للعميل خيار إدارة التطبيق أو العملاء إطلاقاً.
- يدعم تسجيل الدخول المتزامن من أي هاتف أو جهاز كمبيوتر آخر بمجرد إدخال بريده وكلمة المرور.

## 🚀 خطوات الإعداد والتشغيل على cPanel خطوة بخطوة

### الخطوة 1: إنشاء قاعدة بيانات MySQL ومستخدم في cPanel
1. سجل الدخول إلى لوحة تحكم **cPanel** في HostArmada.
2. ابحث عن **MySQL® Databases** (قواعد بيانات MySQL) وافتحه.
3. تحت **Create New Database**:
   - اكتب اسماً للقاعدة (مثال: `sarfy_db` ليصبح الاسم الكامل مثلاً `username_sarfy_db`).
   - اضغط **Create Database**.
4. مرر لأسفل إلى قسم **MySQL Users > Add New User**:
   - اكتب اسم المستخدم (مثال: `sarfy_user`).
   - أنشئ كلمة مرور قوية واحفظها جانباً.
   - اضغط **Create User**.
5. مرر لأسفل إلى قسم **Add User To Database**:
   - اختر المستخدم الذي أنشأته وقاعدة البيانات.
   - اضغط **Add**.
   - فعّل خيار **ALL PRIVILEGES** (جميع الصلاحيات) ثم اضغط **Make Changes**.

---

### الخطوة 2: استيراد ملف `sarfy-database.sql` عبر phpMyAdmin
1. عُد إلى الشاشة الرئيسية في cPanel.
2. ابحث عن **phpMyAdmin** وافتحه.
3. من القائمة الجانبية في اليسار، اضغط على قاعدة البيانات التي أنشأتها للتو.
4. اضغط على تبويب **Import** (استيراد) في الشريط العلوي.
5. اضغط على **Choose File** (اختيار ملف) واختر ملف **`sarfy-database.sql`**.
6. اضغط على زر **Import** (أو **Go**) أسفل الصفحة.
7. ستشاهد رسالة النجاح الخضراء وظهور كافة الجداول الـ 12 (`accounts`, `expenses`, `income`, `transfers`, `debts_owed`, `debts_receivable`, `subscriptions`, `upcoming`, `expected_income`, `goals`, `users`, `user_app_state`).

---

### الخطوة 3: تعديل ملف `config.php`
افتح ملف **`config.php`** بمحرر نصوص (أو داخل File Manager في cPanel) وعدل الأسطر التالية ببياناتك:
```php
define('DB_HOST', 'localhost');
define('DB_PORT', '3306');
define('DB_NAME', 'username_sarfy_db'); // اسم قاعدة البيانات المنشأة
define('DB_USER', 'username_sarfy_user'); // اسم المستخدم المنشأ
define('DB_PASS', 'your_password_here');  // كلمة المرور
define('DB_CHARSET', 'utf8mb4');
```

---

### الخطوة 4: رفع الملفات إلى مدير الملفات (File Manager)
1. في cPanel، افتح **File Manager** (مدير الملفات).
2. ادخل إلى المجلد الذي ترغب بتشغيل الموقع فيه (مثلاً `public_html` للنطاق الرئيسي، أو مجلد النطاق الفرعي).
3. اضغط على **Upload** وارفع الملفات:
   - `index.html`
   - `config.php`
   - `api.php`
   - `htaccess.txt` (وبعد رفعه، أعد تسميته بالضغط عليه بالزر الأيمن واختيار Rename ليصبح `.htaccess`).
   - `manifest.json`
   - `sw.js`
4. ملاحظة: إذا لم يظهر ملف `.htaccess` بعد إعادة تسميته، اضغط على **Settings** في أعلى يمين مدير الملفات وفعّل خيار **Show Hidden Files (dotfiles)**.

---

### الخطوة 5: الفحص والتأكد
1. افتح متصفحك وادخل على رابط موقعك: `https://yourdomain.com/`.
2. ستفتح أمامك شاشة المصادقة المشفرة (Cyber Vault).
3. سجل الدخول أو استخدم الحساب التجريبي.
4. ستلاحظ في أسفل القائمة الجانبية شارة باللون الأخضر: **🟢 متصل بـ MySQL**.
5. ادخل على **الإعدادات والأمان** لتجد قسم **قاعدة بيانات السيرفر (MySQL Server Integration)** الذي يوضح تفاصيل الاتصال، اسم قاعدة البيانات وعدد الجداول، مع زر لفحص الاتصال وزر للمزامنة الفورية.
6. أي عملية إضافة أو تعديل أو حذف تقوم بها ستُحفظ وتُزامن تلقائياً وبشكل ذري في قاعدة بيانات MySQL على السيرفر!
